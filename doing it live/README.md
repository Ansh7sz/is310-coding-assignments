# Portfolio Website

This is my personal student portfolio website for my IS310 assignment. It is designed to showcase a short introduction about me, my interests, and contact information.

## Overview

The site includes:
- A home section with my name and school
- An About Me section with a short personal introduction
- A custom dark theme for a cleaner visual style

## Tools Used

- HTML
- CSS
- GitHub Pages


## How to View

Once GitHub Pages is enabled, the site can be viewed in a browser through the repository’s GitHub Pages link.
