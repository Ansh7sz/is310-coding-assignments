Sachin Tendulkar’s Cricket Bat

This bat is a signed Adidas “Master Blaster” bat used by Sachin Tendulkar, one of cricket’s most celebrated players. In the Qatar Museums collection, it stands as a sports artifact that connects athletic achievement, branding, and museum preservation.

View collection record Read Qatar Museums story

Description

The object represents a piece of cricket history associated with Sachin Tendulkar’s career. It is meaningful not only as sports equipment, but also as a museum object that reflects celebrity, memory, and the global culture of cricket.

The collection text describes it as a used and signed bat, with the front and back carrying the “ST/Sachin Tendulkar” emblem.
